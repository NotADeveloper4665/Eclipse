# Eclipse 0.5.1

Eclipse 0.5.1 adds a Flatpak package for cross-distribution Linux installs and in-stream recording for H.264, HEVC, or AV1 video with Opus audio. Recording saves the compressed stream to Matroska without re-encoding and exposes start/stop controls in the in-stream menu.

This release also includes the FSR and device-forwarding controls under Basic Settings, selectable stream profiles, adjustable minimum-latency frame scheduling, and the compact performance HUD.

Kyber transport support is not included. It requires a compatible host and transport implementation.
