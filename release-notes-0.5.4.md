# Eclipse 0.5.4

Eclipse 0.5.4 adds key-based pairing for Syzygy streaming hosts.

- Pair an unpaired Syzygy host from its context menu with the 48-character host key.
- Verify the host's response and TLS certificate before saving the pairing.
- Keep standard PIN pairing for other compatible hosts.
- Key-paired clients receive the full permission set configured by Syzygy; protect the host key.

This release also includes the 0.5.3 Vulkan Mailbox, FSR recording guard, and settings updates.
